# CampusMind MVP

Mobile-first Next.js starter for the CampusMind academic workspace.

## Run locally

1. Install Node.js 20+.
2. Extract this project.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

## Current screens

- Landing page
- Sign up
- Login
- Academic onboarding
- Dashboard
- Assignments
- Projects
